# Security policy

## Supported versions

Only the latest release gets security fixes.

## Report a vulnerability

Report privately. Do not open a public issue, discussion or pull request.

1. Open the affected repo on GitHub.
2. Go to the **Security** tab.
3. Click **Report a vulnerability**.

This uses GitHub private vulnerability reporting. Only the maintainers see your report.

## What to include

- The affected version.
- Steps to reproduce.
- The impact: what an attacker could do.

## What happens next

- We acknowledge your report within 3 business days.
- We send a status update within 10 business days.
- We credit you in the security advisory, unless you prefer not to be named.
